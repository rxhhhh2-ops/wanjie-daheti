# 万界大合体 · 五术合一推演系统（第一版）

把四柱、梅花、奇门、六壬、紫微五个已通过完整测试的术数工具，整合为一个本地 Web 工具系统：
**一个服务、一个首页、五个板块，点击即进入对应工具页**。

> 所有推演均在本机完成；除你自己配置的 AI 接口外，不向任何外部服务发送数据。

---

## 一、启动

### 方式 A：双击（Windows）

双击 **`启动.bat`**，会自动打开浏览器进入首页。

### 方式 B：命令行

```bat
cd /d "D:\zcodework1\万界大合体\万界大合体第一版"
pip install -r requirements.txt
python server.py --open
```

默认地址：**http://127.0.0.1:8899/**

可选参数：

```bat
python server.py --port 8900      :: 换端口
python server.py --host 0.0.0.0   :: 允许局域网访问（默认只本机）
```

> 依赖：Python 3.10+，`lunar_python`、`lunardate`、`ephem`（见 `requirements.txt`）。

### 应期功能的边界（重要）

- 各工具排盘后的解盘区都有「显示应期 / 关闭应期」开关，**默认关闭**；
- 只显示 `rules/19-应期.json` 登记过、能在古籍或项目校订规则中核对的条目，候选均标出处；
- AI 解盘**默认不输出应期**；只有你在问题中明确问“应期 / 何时 / 多久 / 哪年 / 日期”等，才会按同一份规则回答；
- 原文未列、无法核实或相互冲突的内容不写入：梅花坎/离/艮不推补，奇门六仪带支/星门生克应日、六壬气首候时、八字流月流日、紫微流月流日等均列为缺口；
- 详细命中情况、原文出处与缺口见 `knowledge/08-应期/00-应期资料核查.md`；
- 外部在线排盘与古籍已验证命例的逐项对比、偏差与原因见 `knowledge/08-应期/01-外部命例对比验证-20261031.md`。

### 合一推演：一项数据 → 一个或多个工具

首页主视觉下方有「合一推演」面板：先选数据类型（**命主·生辰** / **占事·时空**），填一项数据，再勾选工具——

- 命主数据可用于 **四柱、紫微**；占事数据可用于 **梅花、奇门、六壬**（勾选范围按数据类型自动过滤）；
- **勾选一个**：直接进入该工具完整页面，自动带入数据并排盘；
- **勾选多个**：在本页下方生成「同参结果」同屏对照，每个工具一个面板，可单独收起或新窗口打开完整页面；地址栏同步为可收藏的合参链接，刷新后原样恢复；
- 占事时若已填命主数据，六壬会自动把生年、性别带入「年命」；
- **合参有出口**：合参面板头部有「复制报告 / 下载 / 打印」——报告由各工具规则引擎的盘面文字自动汇总（约 3–9 千字），可粘进笔记、存为 `.txt`，或直接打印成纸（打印样式只留报告正文，不打印页面外壳）。

数据存于本机浏览器（`suite-data-v1`），跨页通过 URL 参数传递；不带参数访问任一工具页时，行为与旧版完全一致。

**数据会回流**：在工具页改了生辰/性别/占事时间并重新排盘后，新值会自动写回 `suite-data-v1`，回首页即以新数据为准，不必重填。为防误覆盖，回写有四道闸门：只有真实交互（点击/输入/滚轮）之后才允许写；iframe 内的合参面板一律不写；紫微农历入参、梅花的非「年月日时」起卦方式无法无损换回公历时间，故不写；空值不写。

改造细节见 `../万界大合体第一版_合一推演改造.md`、`../万界大合体第一版_三项改造.md`。

## 四、接口

统一同源，五个页面均以**相对路径**访问所在板块的 API：

| 板块 | 接口 |
|---|---|
| 四柱 | `GET /bazi/api/paipan`、`GET /bazi/api/analyze`、`GET /bazi/api/flow`（运程：`scope=years/months/days/hours`）、`GET /bazi/api/lunar`（农历互转：`mode=solar2lunar/lunar2solar/info`）、`GET /bazi/api/reverse`（四柱校验与反推：`y/m/d/t` 为四柱干支，返回 `valid/errors/expected/candidates`，四柱与紫微共用）、`POST /bazi/api/ai`、`POST /bazi/api/ai/stream`（SSE 流式解盘） |
| 梅花 | `GET /meihua/api/cast`、`GET /meihua/api/selftest`、`GET /meihua/api/waiying`、`GET /meihua/api/now`、`POST /meihua/api/ai` |
| 奇门 | `GET /qimen/api/chart`、`GET /qimen/api/now`、`POST /qimen/api/ai`（SSE 流式转发） |
| 六壬 | 纯前端，无后端接口 |
| 紫微 | 纯前端，无后端接口 |

系统状态：`GET /api/health`（首页页脚「五术自检通过」由此读取）。该接口**真跑自检**，不是硬编码：四柱与 lunar_python 交叉对拍一条用例、梅花校验固定起卦结果、奇门校验九宫八门完整性并清点断语库、六壬/紫微校验前端资源；结果缓存 60 秒（`?fresh=1` 强制重跑），任一引擎异常时 `ok=false` 并在页脚变红点名。

## 五、AI 配置说明

### 统一 AI 配置中心（推荐）

- **入口**：首页顶栏「AI 设置」；或任一工具页导航右上角「AI」按钮。
- **一处设置，五术共用**：填写 API 端点 / Key / 模型，可先「测试连接」，再「保存并同步」；
  保存后会写入五个工具各自的本地配置（四柱、梅花、奇门、六壬、紫微），各页刷新后即生效。
- **同步策略**：统一配置更新后，下次打开各工具页会自动覆盖其端点/Key/模型；
  你在某个工具页内单独修改的设置会保留，直到下一次统一配置更新。
- **人设 / 语气**：仍由各工具页单独设置，不参与同步。
- **清除**：统一弹窗里的「清除」会移除本机全部 AI 配置（五个工具一起清空）。

### 各工具调用方式

- **四柱 / 梅花 / 奇门**：页面内的 Key 只存浏览器 localStorage；请求经本机 `server.py` 转发到你填写的 OpenAI 兼容地址，服务端不写日志、不落盘。
- **六壬 / 紫微**：页面直接从浏览器请求你填写的 OpenAI 兼容地址；若浏览器报跨域，请换支持直连的端点或自建本地代理。
- 未配置 API 时，五个工具的**规则化排盘与解盘全部可用**，不依赖 AI。
